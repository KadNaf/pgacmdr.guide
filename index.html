R package pgacmdr · in-app name PGA-commander V1

PGA-commander (Version 1) (PGA-cmdr V1): a graphical, user-friendly and multi-OS interface for the analysis of population genetic data

PGA-cmdr brings allele frequencies, F-statistics, genetic diversity, linkage disequilibrium, null-allele correction and isolation by distance into one Shiny interface. Set a few parameters, press Run, get your file back. Every computation happens on your own machine.

One standardised dataset, ten modules built on it

Most population-genetics work still means juggling several programs, each with its own input format and its own operating-system quirks. PGA-cmdr imports your file once into a single internal structure, and every module after that reads from the same place. Import your data in the first module and the other nine are ready to use, in the order you would normally reach for them.

The ten modules, in the order you'll run them

  1. 1

    Import Data

    Read a CSV or TXT file, assign the population, marker and optional coordinate columns, and build the internal dataset every other module uses.

  2. 2

    Allele Freq

    Allele frequencies at every marker, in every population, with a global column pooling all of them.

  3. 3

    General Stats

    Point estimates of Ho, Hs, Ht and the Weir & Cockerham F-statistics, plus optional standardised differentiation measures.

  4. 4

    Local Panmixia

    Tests random mating within each population (FIS), with bootstrap confidence intervals and a two-sided permutation test.

  5. 5

    Global Panmixia

    The same question for the whole dataset treated as one population (FIT).

  6. 6

    Subdivision

    How different your populations are from each other (FST), with a one-sided permutation test and a genotypic G-test run alongside it.

  7. 7

    Diversities

    Gene diversity within and across populations, with confidence intervals resampled over individuals, subsamples or loci.

  8. 8

    LD

    Pairwise linkage disequilibrium between markers, within each population and pooled, by permutation.

  9. 9

    Null Alleles

    EM-estimated null-allele frequencies, ENA-corrected FST, and every pairwise chord distance between populations.

  10. 10

    IBD

    Isolation by distance: Rousset's regression and a four-statistic Mantel test against geodesic distance.

Every module ends the same way: one Run button, one download, no separate export step. Nothing is kept on screen; the downloaded file is the record of the run.

Built to replace a shelf of separate tools

Accessible
No programming required once installed. The application opens in your own browser and runs identically on Windows, macOS and Linux.
Unified
One input format for the core analyses instead of reformatting data for Fstat, FreeNA, Genepop and the rest in turn.
Transparent about its limits
Where a result is still under comparison against a reference implementation, the documentation says so rather than rounding the discrepancy away.
Fast at real scale
C++ compute kernels parallelised with OpenMP; a 10,000-permutation linkage-disequilibrium run that takes days in some older tools finishes in seconds.

The statistics, and where they come from

Every procedure in PGA-cmdr is a published method, cross-checked against an independent implementation where one exists. This is the index used throughout the application's own documentation.

  • F-statistics FIS, FST, FITWeir & Cockerham (1984)
  • Gene diversity Ho, Hs, HtNei & Chesser (1983)
  • Genotypic test of subdivisionGoudet, Raymond, De Meeûs & Rousset (1996)
  • Null-allele frequency (EM algorithm)Dempster, Laird & Rubin (1977)
  • Null-allele correction of FST and distancesChapuis & Estoup (2007)
  • Chord genetic distanceCavalli-Sforza & Edwards (1967)
  • Isolation-by-distance regressionRousset (1997)
  • Geodesic distance between coordinatesVincenty (1975)
  • Continuity-corrected permutation p-valuesPhipson & Smyth (2010)

Download & install

PGA-cmdr needs R 4.1.0 or later (r-project.org, Windows / macOS / Linux). The package itself is distributed through R-universe, which builds ready-to-use versions for all three platforms, nothing else to download or compile by hand.

install.packages("pgacmdr",
  repos = c("https://kadnaf.r-universe.dev", "https://cloud.r-project.org"))

Then start it with one command, every time you want to use it:

pgacmdr::run_app()

To update later, run the same install.packages() command again; there is no need to remove the previous version first.

The source code lives at github.com/KadNaf/PGA-cmdr; cloning it by hand is only useful if you want to read or modify it, it isn't part of the normal install.
